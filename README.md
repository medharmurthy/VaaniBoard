# Vaani Board

A voice-first AI whiteboard for Indian classrooms. Built for the Cline AI Builder Hackathon (Round 2).

## The problem

In many government schools in India one teacher takes several grades at once, often in two or more languages. She has little time to prepare and almost no good digital content in her pupils' language. Some teachers also have visual or motor disabilities that make clicking, dragging and typing hard. The result is that a lot of children study from notes written in a language they don't think in.

## The idea

The teacher talks to the board the way she normally talks in class, and the board responds.

- "Board pe water cycle ka mind map banao"
- "Assamese mein ek simple counting activity banao"
- "Is chapter ka exercise dikhao"
- "Pichhla action undo karo"

Vaani Board turns that speech into visuals, games and quizzes that match the syllabus, in the language the class needs. A Cline SDK agent does the reasoning. It looks things up in the NCERT books before it draws anything and shows where each answer came from. Maths, letters and counting are generated by code, so they are always correct. Nothing from the teaching assistant goes on the board until the teacher approves it.

This project is a fork of [Trido](https://github.com/Ardelyo/trido), a voice-controlled whiteboard built for an Indonesian teacher with motor disabilities. We kept its board and widgets and changed the AI and the language layer. The full design is in [`plan.md`](./plan.md).

## How a command flows

1. The teacher speaks. `ChatInterface.tsx` or `useAmbientListener.ts` turns the audio into text.
2. `useGeminiBrain.ts` handles quick commands like undo or read aloud straight away. Anything else goes to `/api/ai/generate`.
3. `server/aiRouter.ts` runs the model with the tools from `server/aiTools.ts` and sends back a list of tool calls.
4. `useAgentProcessor.ts` runs those calls, and `CanvasManager.tsx` and `DomOverlay.tsx` draw the result.

## Running it locally

You need Node 22 or newer.

```bash
npm ci
cp .env.example .env    # then add your Gemini key, or point it at a local Ollama
npm run dev             # http://localhost:3000
```

Other useful commands

```bash
npm run check           # fast typecheck with tsc --noEmit
npx vitest run          # tests
npm run build           # production frontend build
npm run electron:dev    # desktop app
```

For offline mode, install [Ollama](https://ollama.com) and run `ollama pull gemma4:e2b`.

## How Cline is used

Cline was our coding partner for the whole build. We used Plan and Act modes, checkpoints and repo rules. The product also uses Cline. The `@cline/sdk` agent is the brain of the board. It picks tools, searches the syllabus and plans multi-step lessons across Gemini, Sarvam and Ollama. See section 5 of `plan.md` for details.
